## 3. Key architectural decisions

### 3.1 Database path resolution (CRITICAL)

`app/__init__.py` has a `_resolve_db_uri()` function:

- Reads `DATABASE_URL` from env, but **only trusts Postgres URLs**
- For SQLite, **always computes an absolute path** from `__file__` -> `<project_root>/data/exchange.db`
- Creates the `data/` directory itself before returning

**Why:** Flask-SQLAlchemy silently resolves relative SQLite paths against `instance_path`, not `cwd`. This caused hours of debugging — server read `instance/data/exchange.db` while scripts wrote to `data/exchange.db`.

**Never revert this.** If you see `no such column` or `unable to open database file`, check `[app] DB URI:` printed on startup — it must point to `~/aflathoon_exchange/data/exchange.db`.

### 3.2 Margin model (6.5% single spread)
mid_rate = market mid (from FALLBACK_RATES or API)
customer_rate = mid_rate x (1 - 0.065) <- spread embedded here
gross = amount x customer_rate
net_to_customer = gross <- NO second deduction
platform_fee = gross x (margin / (1 - margin)) <- informational only

text

**Do NOT** deduct 6.5% twice. Earlier versions did, causing customer to lose ~13%.

`PLATFORM_MARGIN_PCT=0.065` in `.env` is the single source of truth.

### 3.3 Rate engine with layered fallback

1. **Live API** (if `RATES_MODE=live` and API key set) — TickerLayer or SiftingIO
2. **Cache** (last successful fetch, within `RATES_STALE_AFTER_SECONDS=300`)
3. **Fallback** (`FALLBACK_RATES` hardcoded, always available)

Background thread refreshes every `RATES_REFRESH_SECONDS=60`.
`source_info()` returns `{source: 'live'|'cache'|'fallback', last_error, ...}`.

Currently `RATES_MODE=demo` -> always fallback. To go live: set `RATES_MODE=live` and add API key to `.env`.

### 3.4 License guard (safety net)

- `assert_live_trading_allowed()` — aborts with 451/503 if licenses missing
- `missing_licenses()` — returns list of license types required but not active

Called from `/exchange/book` only. `/exchange/convert` (indicative quote) is **not** gated — quotes are free, bookings are not. Intentional.

**To enable live booking:**
1. Register all required licenses at `/compliance/`
2. Mark them `status='active'` and set valid `expiry_date`
3. Set `LIVE_TRADING_ENABLED=true` in `.env`
4. Restart

### 3.5 War-risk premium (loss prevention)

- `HIGH_RISK_CORRIDORS` — hardcoded list (IR, RU, SY, YE, LY, UA, IL)
- Base premium 0.25% of freight; max 5% for high-risk
- `AUTO_HEDGE=true` adds surcharge if premium exceeds what 6.5% margin can absorb

**Why:** war-risk insurance premiums can spike from 0.25% to 3%+ overnight. Without this, platform sells below cost.

### 3.6 Booking flow
Client -> POST /exchange/convert -> quote only (no DB)
Client -> POST /exchange/book -> creates Transaction row
status = STAGED by default
status = CONFIRMED if admin + LIVE_TRADING_ENABLED + licenses OK

text

Reference format: `TX-YYYY-NNNNNN`.

Margin snapshotted at booking time in `margin_amount`.

### 3.7 Theme system

- Cookie `afl_theme` with values `dark` | `light` | `auto`
- Set via `data-theme="..."` on `<html>` before CSS parses (prevents FOUC)
- All colors via CSS variables in `app/static/css/admin.css`

Every page extends `base.html` **except** `auth/login.html` and `auth/register.html` (standalone, but theme-aware).

def _resolve_db_uri() -> str:
    env_url = (os.environ.get('DATABASE_URL') or '').strip()
    if env_url.startswith(('postgresql://', 'postgres://')):
        return env_url

    db_file = os.path.join(data_dir, 'exchange.db')
    return f"sqlite:///{db_file}"

7. Auth flow
Flask-Login.

User implements UserMixin

login_manager.user_loader in create_app():

text
@login_manager.user_loader
def load_user(user_id):
    return db.session.get(User, int(user_id))
login_manager.login_view = 'auth.login'

Login: check_password -> login_user(u, remember=True) -> redirect(next_url)

Session cookie: aflathoon_session, HttpOnly, SameSite=Lax

Logout: logout_user() -> /

Session cookie uniqueness matters: aflathoon_session (not session) prevents collisions with other localhost dev servers.

8. Rate limiting
Flask-Limiter, in-memory.

Global default: RATELIMIT_DEFAULT=100/hour (not currently enforced per-route)

Move to Redis: RATELIMIT_STORAGE_URI=redis://localhost:6379/0

Recommended:

/auth/login: 5/minute per IP + per username

/exchange/book: 60/minute per user

/admin/api/*: 300/minute per admin

9. Backup & sync architecture
Database: scripts/backup_db.sh uses sqlite3 .backup (safe while running). 30 daily copies in data/backups/. Cron 03:30.

Full snapshot: scripts/backup_full.sh includes DB copy, .env shape (redacted), manifest. 14 snapshots in backups/.

Git sync: scripts/git-sync.sh stages all, commits if changes, pushes. Cron 03:15. DB, .env, venv/, installers gitignored.

10. Failure modes
Symptom	Root cause	Fix
ModuleNotFoundError: flask	venv not active	source venv/bin/activate
unable to open database file	DB path broken	Check _resolve_db_uri()
no such column: X	Model changed, table not migrated	ALTER TABLE OR Flask-Migrate
Login POST returns 200	Wrong password / cookie dropped	Check [LOGIN] debug lines
Port already in use	Another process	pkill -f "python app.py"
Two banners printed	Debug reloader running	Check use_reloader=False
Wrong theme	Doesn't extend base	grep -L "extends"
Template not found	Missing directory	mkdir -p app/templates/<dir>
11. Extensibility
Adding a service: app/services/new_service.py -> import in route. If stateful, add get_singleton() pattern.

Adding a model: app/models/new_model.py -> register in __init__.py -> ALTER TABLE or Flask-Migrate.

Adding a route module: new file with Blueprint -> register in routes/__init__.py -> register in create_app().

Adding a template: must start with {% extends "base.html" %}.

Adding an admin API: in admin.py with @admin_required, return jsonify(...).

Adding a theme: add [data-theme="yourtheme"] {...} to admin.css + option in base.html.
